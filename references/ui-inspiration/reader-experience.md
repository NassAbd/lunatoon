# Reader experience — POC 06

The reading strip remains a single vertical document. Each submitted decision stays above its two panels; neither submitting, receiving dialogue, receiving a preview nor completing an image scrolls the reader automatically. A new chapter never replaces an earlier one.

## Waiting and arrival

1. **Writing:** keep the selected choice and optional instruction visible. The existing reserved status area acknowledges the request immediately.
2. **Dialogue:** persist the validated script, paint the dialogue, then launch both image requests concurrently.
3. **Illustrating:** reserve the final portrait dimensions. Original, static station-line geometry supports the noir palette; the accompanying text clearly says the illustration is still being made. This decoration is not an intermediate model image or a progress indicator.
4. **Artwork:** decode each image before revealing it independently. The final fade is 220 ms, with a reduced-motion alternative. Actual provider previews retain their explicit preview label. A provider may return only its final image.

Failure copy explains what remains saved and offers an explicit isolated retry. It does not conceal paid retry implications. Developer details remain closed initially, including cost accounting, image-mode replay and request timings.

## Opening and typography

Four authored beats form the opening: city → detective → device → surveillance. The original Kael illustration and reference stay untouched. New vector compositions use the existing palette and tell different beats rather than repeating a crop. Short HTML captions carry the canonical opening; they are not baked into artwork. A historical opening's supplied text is preserved if it differs from the canonical scenario.

The three new vignettes are public presentation assets, not new generation references or database records. Existing saved opening/reference assets remain hash-pinned. Future edits to the public vignettes would change their presentation on earlier runs; version them deliberately if future presentation preservation is required.

Generated dialogue retains its established placement contract and collision resolution. High-contrast light balloons, speaker labels and wrapping remain readable over dark artwork. Never change generated story facts to accommodate a layout.

## Navigation and privacy

The library separates a playable story from an explicitly upcoming concept. Saved sessions belong to this local installation, with no accounts or ownership claims. Opening a session does not schedule generation. A read-only catalogue query must not invoke engine recovery, mutate state or reveal instructions, dialogue, diagnostics or usage in the catalogue payload.
