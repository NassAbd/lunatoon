They were taken against an isolated temporary workspace using the production test build. Capturing them made zero foundation, narrative or image-generation calls. Screenshots are UI illustrations, not live-generation quality evidence.

The two `poc-03-1-*.png` files are retained historical screenshots. Their context is preserved in the [POC 03.1 report](../archive/poc/POC_03_1_RESULTS.md); they do not show the final interface.
